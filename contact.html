CONTACT

Report a problem or correction.

The public repository is the primary contact channel for this independent project.

Technical reports

Open a GitHub issue with the page URL, expected result, actual result and a minimal sanitized fixture.

Specification corrections

Include a link to the relevant stable MCP Apps specification section or official schema. Reports that reduce false positives and improve protocol accuracy are prioritized.

Privacy and advertising

Title policy-related reports “Site policy inquiry.” Never post secrets, personal identifiers or proprietary server content in a public issue.

Response expectations

Requests are reviewed on a best-effort basis. There is no paid support plan or response-time commitment.
