MCP Apps reference

One URI connects the complete MCP App flow.

Copy a minimal MCP Apps tool, ui:// resource and HTML content snapshot for validator and host testing.

How it works

Inspect the complete boundary.

The tool points to ui://weather/dashboard, the resource declaration publishes the same URI and MIME type, and resources/read returns a complete HTML document under that URI. Resource metadata declares only the external origins and permissions the view needs.

Open the valid sample on the homepage to copy the full JSON. Replace the example names and origins, validate locally, then replay the real MCP server through a supported host.

Continue debugging

  • Run the browser validator.
  • Review sandbox CSP metadata.
  • Resolve resource and metadata errors.
  • Finish with the official conformance tooling and a supported MCP host.
