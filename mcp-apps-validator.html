Static validation starts with a complete snapshot.

Validate MCP Apps tools, UI resources, content and cross-object links with a compact JSON snapshot.

How it works

Inspect the complete boundary.

Copy the relevant entries from tools/list, resources/list and resources/read into the three arrays accepted by the homepage. Tool metadata should use the nested _meta.ui.resourceUri form, and every linked URI should resolve to an included declaration or content item.

Fix parse and field errors before linkage warnings. A clean result is a preparation step for the official conformance CLI and real host testing, not a replacement for them.

Continue debugging

  • Run the browser validator.
  • Review sandbox CSP metadata.
  • Resolve resource and metadata errors.
  • Finish with the official conformance tooling and a supported MCP host.
